# اختبار قارئات الشاشة

قبل الإطلاق تحقق يدوياً من:

1. **VoiceOver (macOS)**: Cmd+F5 — تنقّل Tab إلى زر الأداة، ثم VO+Space لفتح القائمة.
2. **NVDA (Windows)**: تأكد أن عناصر اللوحة لها أسماء مسموعة وأن `aria-live` يعلن التغييرات.
3. **لوحة المفاتيح فقط**: Escape يغلق اللوحة، Tab يبقى داخل الحوار المنطقي.
4. **RTL**: مع `lang=ar` تأكد من محاذاة اللوحة واتجاه النص.
